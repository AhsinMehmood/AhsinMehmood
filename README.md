### ☕ Sugar Goat Cafe — Restaurant Ordering & Delivery System

**~30–40 orders completed daily**

Designed and built a complete direct-ordering ecosystem for a specialty cafe in Phuket, Thailand.

The platform connects the entire order lifecycle through four coordinated applications:

- Customer ordering experience
- Kitchen display system
- Rider delivery workflow
- Admin management panel

Orders move in real time from checkout → kitchen preparation → rider delivery → completion, with one shared source of truth across the system.

**My work:** Product architecture, Flutter/web implementation, Firebase real-time backend, Stripe integration, operational workflows, deployment, and launch support.

**Tech:** `Flutter` `Firebase` `Stripe` `Web`

🌐 [Case Study](https://mehmoodtech.com/projects/sugar-goat-cafe-phuket)
